# 工坊 Claude 风设计规范（已筛选）

本规范从 4 个参考源筛选而来（见 `references/source-filtering.md`），
服务一个目标：把 Float 工坊做成用户截图中的 Claude 聊天界面质感——
温暖、克制、以阅读为中心，而不是营销网站。

## 适用范围与优先级

- 只作用于工坊模块及其抽屉、弹窗、预览区域。不改桌面、书房、角色卷宗等其他应用主题。
- 决策顺序：**用户明确要求 > 项目现有设计约束 > 本规范 > 通用默认**。
- 工坊需要长期一致的阅读界面：禁止为了"每次不同"而强制改布局或加装饰。
- 用户界面截图中的取色、字号、比例优先于本规范数值；本规范数值是起点。

## 色彩（以官方品牌值为准）

```css
--wc-bg: #faf9f5;        /* 暖米白阅读底（官方 light），绝不用纯白 #fff */
--wc-bg-raised: #f0eee6; /* 区块/工具卡片底 */
--wc-bg-inset: #e8e6dc;  /* 官方 light gray，输入区容器可用 */
--wc-text: #141413;      /* 官方 dark，主文字 */
--wc-text-2: #6b6860;    /* 次要文字（暖灰） */
--wc-text-3: #b0aea5;    /* 官方 mid gray，弱化文字 */
--wc-border: rgba(20, 20, 19, 0.08);        /* 细边框 */
--wc-accent: #d97757;    /* 陶土橙，唯一强调色：CTA、发送按钮、聚焦、链接 */
--wc-accent-deep: #c4653a; /* hover/按下态 */
--wc-success: #788c5d;   /* 官方 green */
--wc-info: #6a9bcc;      /* 官方 blue，仅辅助 */
--wc-error: #c0453a;     /* 危险操作用强色，不用克制灰 */
```

规则：
- 页面底永远用暖米白；用户消息气泡可用深色 `--wc-text` 反转。
- 陶土橙克制使用：一个界面里它只出现在最重要的 1–2 处（发送按钮 + 焦点环）。
- 禁止蓝紫渐变、荧光色、冷色调大面积使用。

## 字体与中文排版

- 中文正文：清晰易读的无衬线系统字体栈（PingFang SC / Microsoft YaHei /
  Noto Sans SC 兜底）。**霞鹜文楷不作为聊天正文默认**。
- 欢迎标题可适度使用衬线（Georgia / 宋体系）制造温度，但仅限欢迎页标题等少数位置。
- 不引入未经确认的字体文件；只用系统字体可靠降级。
- 中文正文行高 1.75；正文 ≥ 16px；中文标题字重 400（不用 700）；UI 标签 500。
- 字体栈英文在前中文在后，靠 unicode-range 自然分流。
- 长文区设置 `overflow-wrap: break-word`，标点压缩可用 `text-spacing-trim`。

## 布局与组件要点

- 聊天不用彩色气泡：AI 正文 = 左对齐的文章式排版；用户消息 = 右对齐深色圆角块。
- 圆角：卡片/输入容器 12–16px；小按钮 8–10px；不使用 0px 直角。
- 边框细（1px、8% 深色透明度）优先于阴影；阴影必须暖色低透明度
  （如 `0 2px 12px rgba(193,165,140,0.12)`），不用黑色重阴影。
- 底部输入：圆角容器（约 16px）、内含附件入口 + 自适应增高 textarea + 发送按钮；
  聚焦时橙色边框 + `box-shadow: 0 0 0 3px rgba(217,119,87,0.12)`。
- 工具调用行：默认紧凑折叠，可读摘要（"读取文件"），展开可看参数/结果；
  左侧 3px 暖色竖条 + 浅底，不堆原始工具名。
- 手机优先：触摸目标 ≥ 44px；侧边栏改抽屉；顶部避开模拟状态栏，底部适配安全区。
- 详细组件规格见 `references/chat-ui-spec.md`，中文排版细节见 `references/cn-typography.md`。

## 动效

- 只动 `transform` 和 `opacity`；**禁止 `transition: all`**。
- 时长 150–250ms，ease-out；动效短而自然、可打断。
- 非用户触发的动效克制使用；尊重 `prefers-reduced-motion`。
- 流式输出用小批次平滑更新；不为表演增加明显等待。

## 明确不采用（筛选掉的社区规则）

- ❌ 每次输出强制差异化、必须加"非标准元素"（工坊需要稳定一致）
- ❌ "纯色背景廉价"、渐变 mesh/噪点/几何纹理背景（聊天界面要干净阅读底）
- ❌ 营销页大留白（64px+ 区块间距）/ 非对称构图 / 突破容器边界
- ❌ PPT/海报章节规则
- ❌ 霞鹜文楷作为正文默认；Lora/Poppins 品牌字体作为聊天 UI 必需品
- ❌ 官方 frontend-design 中"警惕米色+陶土橙是 AI 套路"的提醒——本项目用户
  明确指定 Claude 风，brief 锁定方向，按该 skill 自己的规则"用户要求优先"

## 文案

- 界面语言用用户能懂的话（"读取文件"而非内部工具名）；主动语态；
  按钮写清楚发生什么（"发送"而非"提交"）。
- 错误态给出解释和下一步，不卖萌不卖惨；空状态是行动邀请。
- 助手名称显示为 Claude，聊天自称"克克"。

## 验收检查

- [ ] 新样式只作用工坊，其他应用视觉未变
- [ ] 色彩/圆角/阴影全部走 token，无蓝紫渐变、无纯白底
- [ ] 正文中文无衬线、行高 1.75、≥16px
- [ ] 无 transition: all；reduced-motion 有降级
- [ ] 触摸目标 ≥ 44px；键盘弹出后发送按钮可见
- [ ] 声明为"示例"的预览内容有明确标注，未伪造工具运行
