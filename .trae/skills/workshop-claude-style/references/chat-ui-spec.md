# 聊天界面组件规格（移动端优先）

改编自 anthropic-style-cn 的 chat.md 组件规范（经筛选：去掉桌面侧边栏常驻、
营销化处理；适配 Float 工坊的手机形态与现有功能）。类名以 `wc-` 前缀隔离，
避免污染现有全局样式。

## 消息流结构

- 容器：`role="log"` + `aria-live="polite"`；`overscroll-behavior: contain`。
- AI 消息：左对齐、文章式排版（无气泡背景），正文最大宽度 ~680px 居中列。
  - 头部一行：24px 橙色底圆角小图标 + "Claude" + 时间（弱化灰）。
  - 正文：16px / 行高 1.75 / `--wc-text`；段落间距 12px。
  - 列表/引用/表格/代码块按 Markdown 语义渲染；表格横向滚动不撑宽页面。
- 用户消息：右对齐、深色圆角块（`--wc-text` 底 + `#faf9f5` 文字），
  圆角 `16px 16px 4px 16px`，内距 12px 16px，最大宽度 85%。
- 工具调用行（AI 消息内）：
  - 默认折叠单行：图标 + 可读摘要（"读取文件 components/x.tsx"）+ 展开箭头。
  - 展开后：浅底（`--wc-bg-raised`）+ 左侧 3px `--wc-accent` 竖条，
    参数与结果用等宽小字，结果可复制。
  - 运行中图标转圈；失败标红并给出可重试入口。
- 消息操作（复制/编辑）：气泡下方，图标 28px、点击区 44px，生成中不显示。

## 流式与状态指示

- 生成中：文字用纯文本流式渲染（增量不全量重排 Markdown），结束后切完整渲染。
- 等待首字节：三点跳动指示（橙色圆点，`transform/opacity` 动画，1.2s 循环）。
- 状态摘要（第二批接入真实事件）：紧凑一行，例如"正在处理需求 · 已运行 12s"，
  不用百分比假进度。

## 底部输入区

```
[圆角容器 16px，底色 --wc-bg-inset，1px 边框]
  [附件按钮 44px] [textarea 自适应增高，max ~160px] [发送按钮 40px 圆形橙底白箭头]
容器下方居中小字："克克也可能出错，请核实重要信息"
```

- 聚焦：边框变 `--wc-accent` + 3px 橙色柔和外环。
- 空输入时发送按钮禁用态（灰底 50% 透明）。
- 键盘弹出：容器保持可见（适配 safe-area-inset-bottom）。
- 已实现语音输入时才显示麦克风；不摆假按钮。

## 输入框附近的紧凑选择控件

- 模型选择 / 仓库分支：小型下拉，弱化灰小字，显示**真实**连接信息；
  未连接显示真实空状态，不硬编码"Opus 5 / main"。
- 放在输入容器上方一行或作为容器内下拉，不占大面积。

## 抽屉（手机侧边栏）

- 从左滑出，宽 78%，暖米白底 + 右侧 1px 细边框 + 轻阴影。
- 内容：新会话按钮（橙底白字圆角）、会话历史列表（今天/昨天分组，
  active 项橙色 10% 底 + 标题橙字）、仓库配置、云端电脑配置、
  技能入口（第一批显示"尚未配置"）。
- 打开时背景遮罩 rgba(20,20,19,0.32)；Escape/点遮罩可关；焦点困在抽屉内。

## 修改提案卡片

- 状态标题（修改提案/已提交/已撤销/已取消）+ 分支 + 文件数。
- 文件列表每行：路径 + 删除项标红；错误信息红字（`--wc-error`）。
- 操作按钮：应用（橙主按钮）/ 取消（弱化按钮）；危险操作明确警示文案，
  不绕过现有确认逻辑。

## 附件与文件卡片

- 名称 + 类型徽章 + 大小 + 状态（上传中/已读取/失败）。
- 可打开已有预览或下载；二进制未解析时如实显示"不支持预览"。

## 预览区（文件/代码/作品）

- 手机：全屏子页（顶部返回 + 标题 + 关闭），桌面可侧面板。
- 入口、返回、关闭不互相遮挡。

## 空/加载/错误状态

- 加载：骨架或单行"加载中…"，不假装进度。
- 断线/失败：说明原因 + 重试按钮；取消有明确状态。
- 欢迎页：居中克克/Claude 标识 + 衬线中文欢迎标题 + 简短说明 +
  建议问题芯片（1px 边框圆角胶囊，点击即填入输入框）。
