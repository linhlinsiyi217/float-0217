## 五、问题和原始报错

1. **推送失败（需要你手动处理凭据）**。最后一次原始报错：
   ```
   remote: Permission to linhlinsiyi217/float-0217.git denied to linsiyi520.
   fatal: unable to access 'https://github.com/linhlinsiyi217/float-0217.git/': The requested URL returned error: 403
   ```
   原因：Windows 凭据管理器（git 用的是 credential.helper=manager）里缓存的账号是 **linsiyi520**，它对 `linhlinsiyi217/float-0217` 没有写权限。任务5/6 当时推送成功过，说明中途凭据被换掉了。
   修法：打开 Windows「凭据管理器」→ Windows 凭据 → 删掉 `git:https://github.com` 相关条目 → 再执行 `git push origin trae/overnight-1`，弹登录框时用 **linhlinsiyi217**（或有写权限的账号）登录。我没有动凭据配置。另外更早一次 push 曾被本机安全策略拦截（"requires explicit user approval"），重试后遇到的就是上面这个 403。
2. **任务4 的「变暗」没做**：小弹窗的验证式交互完成了，但弹窗弹出时背景变暗的遮罩效果没有实现，留待你确认要不要加。
3. **锁屏是模拟的**：任务7 的锁屏是应用内界面模拟（时钟、PIN 键盘、解锁动效），不是系统级锁屏；PIN 只在本机校验，不接系统锁。
4. **时光回溯是占位**：线下底栏菜单里点「时光回溯」目前只弹提示「时光回溯还在开发中」，回溯逻辑还没写。
5. **删段=删整轮**：线下存储按 turn 制（一轮 = 你写的+TA写的各一段），删除某一段实际删掉的是它所属的整轮，界面上前后两段会一起消失。
6. **PowerShell 不支持 heredoc**：中途一次 commit 因为用了 bash 的 `<<'EOF'` 语法报 `The '<' operator is reserved for future use`，改用 `git commit -F 临时文件` 完成，无影响。

## 六、活人感清单（任务9：只出方案，未改代码）

**总判断**：Float 的 AI 味主要来自提示词只有「格式约束」没有「人格与运行逻辑」。线上 `lib/builtin-preset.ts` 的 chat_immersion_instruction（L128 起）只规定微信体 1-4 句；线下 chat_offline_format（L583 起）只规定 XML 格式加一串禁令。曲曲的 preset-seed.js（§0-§5）补的正是「一个人是怎么运转的」，逐条对比如下，每条格式为：Float 现状 → 曲曲做法 → 准备怎么改。

1. **信息边界**
   现状：没有信息归属规则，模型容易替用户编近况、造共同回忆。
   曲曲 §0.2：用户侧事实只能来自五处——角色设定、用户设定、世界书、对话历史、当前输入；五处都没有的就是不知道，不许猜、不许「忽然想起来」。
   准备怎么改：给线上线下两套 preset 各加一段信息边界条款（纯提示词，风险最低）。

2. **情绪不归零**
   现状：每轮独立生成，情绪默认重置，上一轮的余味会消失。
   曲曲 §1.2：情绪带衰减延续、可叠加（心疼里裹着无奈）、按人设藏情绪、长时间负面对话会把人耗空。
   准备怎么改：先加提示词条款；二期可把上一轮情绪摘要注入上下文（改动大，先不动）。

3. **表达有上限**
   现状：模型默认每次都给出恰到好处的回复。
   曲曲 §1.3：经常找不到词、想说 A 说成 B、安慰人越安慰越笨。
   准备怎么改：一句话条款，并进「怎么说话」段落。

4. **自己在走的人生**
   现状：角色基本围着用户转，空档时间是空的。
   曲曲 §1.4：空档时间真的在走、主业在推进也出难题、有自己的社交圈（禁「某朋友」占位称呼）、有想要的和拖延马虎等毛病。
   准备怎么改：先加提示词条款；二期可接 Float 已有的日程/感知能力让空档状态落到数据上。

5. **先感觉后逻辑**
   现状：无此约束，模型默认逻辑优先。
   曲曲 §1.5：先感到整体气场再读懂字面，思维可乱可跳，预判可能出错。
   准备怎么改：并进「怎么说话」段落。

6. **语言指纹 + 话是掉下来的**
   现状：只有句数格式约束，角色说话方式的区分靠人设文本自觉。
   曲曲 §2.1/§2.2：稳定到能被认出的语言指纹（丢主语、半截话、改口、口头禅）；话是人格和情绪自然掉落的结果，禁刻意造句、制式安慰、AI 腔。
   准备怎么改：合并成一段「怎么说话」写进两套 preset。

7. **六类硬禁清单**
   现状：禁令零散，且只列禁不给替代。
   曲曲 §3：身体描写模板（勾起唇角/喉结滚动→改成「笑了」「声音低哑」）、网文烂梗比喻（石子投入心湖/小兽）、抽象情绪总结（难以言喻/心猛地一沉→用具体行为顶上）、装腔对白（呵/哦？）、支配姿态、分析腔（逻辑/变量/bug）。每类都带「改写成」的正例。
   准备怎么改：按六类补齐，**禁令后面必须跟替代写法**——曲曲的经验是只列禁令模型会换着花样犯。

8. **没有读心术（线下专属）**
   现状：线下模式无此约束，TA 会精准接住所有暗示。
   曲曲 §4.1：只能靠对方言行判断、判断可能错、暗示可能完全没接住。
   准备怎么改：写进线下 prompt。

9. **文风/氛围/视角模板（线下专属）**
   现状：任务8刚搭好线下写作参数的注入管道（chat-engine.ts / group-chat-engine.ts），但只有自由文本框，用户得自己想词。
   曲曲 preset-offline-seed.js：四套文风模板、五套氛围模板、五种视角选一、心理描写开关。
   准备怎么改：把模板做成设置页可点选项，加心理描写开关；模板文案直接参考已采集的曲曲素材。

10. **心声弹窗校准**
    现状：任务6的心声由通用 prompt 生成，没套「不归零/表达上限/先感觉」。
    准备怎么改：心声生成 prompt 复用同一套底层运行逻辑条款。

**执行顺序建议**：先做 1、2、5、6、7、8（纯提示词，风险最低见效最快）→ 再做 3、4 一期 → 然后 9（需要设置页改动）→ 最后 4 二期（要接日程数据）。
